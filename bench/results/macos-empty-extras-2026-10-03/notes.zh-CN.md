CPU 包含客户端和服务端，以单核 100% 计。全屏未改善；局部小幅差异与运行波动重叠，不能证明稳定收益。历史后 physical footprint 中位数 129.75 → 129.89 MiB，未见内存收益。全屏 DSR p95 中位数 0.680 → 0.916 ms，p99 0.907 → 1.338 ms，也不能宣称响应无退化。各场景解析期限 miss 为 0。DSR 不等于客户端呈现完成。

结论：撤回 01e9968，不合入 main，不安装。未以该候选主张 CPU 优化，所以没有继续为它跑 GPU 帧数确认。前一中断批次单独保存在 interrupted，不纳入统计；并发 Rust 构建被检测到后自动停止。

测量同时修复了启动计时：本机 Python monotonic_ns 在不同进程的起点不一致，旧跨进程相减可出现负值。b46c929 对启动时间改用系统 Mach 绝对时钟，新增真正跨进程测试；本批所有启动时间为正。CPU libproc 累计值及单进程场景耗时不受此问题影响。14 项 Python 测试、cargo fmt --check、workspace clippy 通过。
